# Layout - portfolio.edgarkretschmann.com

## Global
- **Background:** White (`#FFFFFF`).
- **Font:** Inter (Global).
- **Layout:** Multi-column / Full-page sections.

## Sections
1. **Project Cards**
   - Full-width or split sections for each project.
   - High contrast backgrounds (e.g., Light Blue).
2. **Navigation**
   - "Next Project" links.
   - Detailed project links pointing to subdomains.
3. **Footer**
   - "Get in touch!" section.
   - Thank you note.

## Responsive Behavior
- Clean, grid-based or stacked layout.
- High contrast and bold typography.

## Interaction Model
- **Sectioned Navigation:** Links between distinct project pages or sections.
- **External Links:** Deep links to `projects.edgarkretschmann.com`.
