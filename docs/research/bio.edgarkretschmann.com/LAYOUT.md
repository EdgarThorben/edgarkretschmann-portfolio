# Layout - bio.edgarkretschmann.com

## Global
- **Background:** White (`#FFFFFF`).
- **Font:** Lexend Deca (Headings), Inter (Body).
- **Layout:** Multi-section vertical scroll with alternating images and text.

## Sections
1. **Hero Section**
   - Image at top.
   - Arrow down indicator.
2. **Chronological Sections**
   - Large year indicators (e.g., 2018/19).
   - Text content and associated images.
3. **Interstitial Images**
   - Full-width images between major content sections.
4. **Footer/Contact**
   - "Get in touch" buttons.
   - Arrow up indicator.

## Responsive Behavior
- Large headings (84px) on desktop.
- Stacked sections for mobile.
- Mobile-first approach.

## Interaction Model
- **Vertical Scroll:** Content is consumed chronologically.
- **Navigation:** Simple anchors and external links.
